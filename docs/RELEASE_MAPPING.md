# Public naming and provenance
Public resource: ELEC-VQA dataset. Package/module: elec_vqa. Public folders and configurations omit private development-version labels. Stable sample, circuit and drawing IDs are unchanged. Annotation legacy version tags and duplicate legacy wording fields are removed; questions, answers, evidence, splits, graphs and image bytes are retained. Source DWGs, intermediate backups, rejected samples, local environments, secrets, trained adapters, old results and personal review files are excluded. Final automatic predictions/scores remain unchanged for reproducibility. This is a release candidate with licensing pending, not an already published GitHub repository.
