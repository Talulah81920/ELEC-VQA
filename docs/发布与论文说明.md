# 最终整理说明

本目录采用统一公开名称 ELEC-VQA。历史实验中的样本 ID 保持不变，以便逐条核对原始预测与评分；ID 中的字符不是公开版本名称。数据和代码的历史目录名已从公开运行入口移除。原工作目录未覆盖。

当前论文和网页采用 results/assistant_review 中的暂定补分结果；原始 Qwen 评分独立保留，未被覆盖。新增结果见 RESULTS.md，以及 results/assistant_review/publication 与 deep_analysis 中的图组：正确答案的证据支持比例、受控变化配对、条件数和路径长度。完整正反结果均保留。E 的优势应表述为更高的证据支持质量及部分条件推理收益，而不是总体答案准确率全面提高。

论文采用学术表述，实验执行日志、服务器路径和调度细节不进入正文。模型、提示、划分、评分标准与统计局限仍需保留，它们属于必要的方法信息。英文 PDF 与中文阅读稿位于 paper。作者姓名、单位和最终仓库地址尚需作者填写。
