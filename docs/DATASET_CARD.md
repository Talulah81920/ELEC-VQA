# ELEC-VQA dataset
10,201 English QA records, 1,019 image configurations, 300 original windows and 719 controlled variants; 44 drawings from 14 substation projects. Train/validation/test: 6972/1155/2074 QA. Primary test excludes ten T14 controls (2064 questions). Images are local schematic windows, not independent circuit designs. Original windows can overlap. Two training views share IDs and inputs. References are automatically graph-checked annotations, not independently expert-validated gold. Evidence is an observable justification, not a claim about hidden model reasoning. IDs retain their stable prefixes to preserve links to experimental predictions; these prefixes are identifiers, not dataset version names. Source provenance remains in the annotations.
