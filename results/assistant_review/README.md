# 未决评分的暂定归类与人工审理

本目录是独立的暂定分析层，不覆盖 `results/scores/` 中的原始 Qwen 评分，也不宣称人工审核已经完成。仅处理测试集三个评分轨道中原先为 null 的 585 条记录，涉及 517 道 QA、552 个模型响应。答案和证据各算一次评分，因此这些数量不同。

## 当前使用方式

- `index.html`：打开即可审理，包含题目、截图、完整响应、参考答案/证据、暂定分数、理由及 Qwen 原始理由。
- `tables/`：按暂定分数更新的总体、任务和图纸来源表格。
- `final_analysis/`、`deep_analysis/`：按暂定结果重算的图与联合指标。
- `review_queue.json` / `.csv`：全部待审条目，人工分数字段尚未填写。
- `provenance.json`：原始文件哈希与处理数量。

答案评分只衡量最终答案。正确的 Yes/No 不因简短而扣分。证据评分单独检查显式支持；只有答案和证据都为 3，联合指标才通过。未决记录中的暂定分数既包括参考相对的助手归类，也包括对原始裁判尝试数字建议的恢复；`method` 字段逐条区分。原裁判的数字建议不等于独立复核，更不等于专家标注。

优先检查：暂定为 3 的条目、原始理由与参考矛盾的条目、最终答案正确但说明自相矛盾的条目，以及省略具名触点的路径是否只算不充分证据。页面可筛选这些条目，但所有 585 条均保留。

## 保存与回填

页面选择的人工评分只保存到当前浏览器，本地缓存可能被浏览器清理。完成后点击“导出审核 JSON”，保存文件，再运行：

```bash
python scripts/resolve_unresolved.py --human-labels /path/to/human_review.json
python scripts/analyze_provisional.py
```

脚本将按响应哈希校验，只有明确填写的人工分数才标记为 `human_confirmed`；其余仍为暂定。原始 Qwen 评分始终不被覆盖。当前论文 PDF 主表已按用户要求采用本目录的暂定补分结果，并注明混合评价来源及待人工确认状态；原始 Qwen 结果保留为敏感性分析，不能把混合评分写成“全部由 Qwen 裁判产生”。
